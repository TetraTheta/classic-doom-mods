# Universal I-Frame

Gives a player a short invulnerability window after taking damage from another source. During the window the player sprite flashes. Self-inflicted damage does not start the window.

| Server CVar | Default | Effect |
| --- | ---: | --- |
| `iframesDuration` | `12` | Duration in ticks; `0` disables the effect. |

Change the value with the **I-frame duration** slider in UZDoom's Options menu (range `0`–`35`) or through the console/server configuration. No special load order is required.
