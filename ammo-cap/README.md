# Ammo Cap

Sets the maximum amount of each player ammo type, including ammo types added by other mods. The cap is applied when a player spawns and updated during play. It changes capacity; it does not grant ammo.

## Setting

| Server CVar | Default | Effect |
| --- | ---: | --- |
| `ds_ammo_max` | `9999` | Maximum amount per ammo type. Values below `0` act as `0`. |

Set the CVar in the UZDoom console or your server configuration. No special load order is required.
